# 拓扑优化（密度法）——独立算法线方案（2026-09-12）

> 用户 09-12 原话：「可以重新开一条算法，不要再动现有收尾的APP，验证完再收编，我们用密度法(但圆盘法兰形状必须守住)」。
> 本方案只定「做什么、怎么验、什么算成」；代码放在独立项目 `Pt_Topo`（引用 `Pt_Optimize` 的 Core，**不改 APP 一行**），结果走 .3dm 路径回 APP 过判据才算数。

## 1. 目标与边界

| 项 | 定 |
|---|---|
| 目标 | 在判据全过的前提下，找出舌片与圆盘上**该挖掉的料**（孔、槽、镂空），使法兰铂重最小 |
| 守住的形状（不许动） | 圆盘外圆（盘径）、管孔与焊环（孔缘外一圈 = 焊脚 + 2 mm 实料）、舌片外轮廓（舌长、舌端宽、平行或锥形）、压接段（舌端 40 mm 整段实料，铜排夹住） |
| 可动的 | 圆盘内环带（焊环外到盘缘内 2 mm）与舌片非压接段里**每一格有料无料** |
| 厚度 | 先固定为现有解的板厚／舌片厚／叉臂厚（第一阶段只挖不变厚）；第二阶段再把每格厚度放进变量 |
| 判据 | 与 APP 同一套：法兰截面 J ≤ J+1（逐格电流密度作局部约束）、管孔净流入 > 0、圆盘区最高温 ≤ 5 K、法兰增量温降 ≤ 10 K、不熔化、舌片自由段、圆盘盖得住管孔 |

「圆盘法兰形状必须守住」我按**外圆不动、盘内允许挖**理解；若用户的意思是盘上一个孔都不许开、只在舌片上挖，把可动区改成「舌片非压接段」即可，算法不变。

## 2. 密度法怎么套到这个问题上

- 变量：每格密度 ρ_i ∈ [0, 1]；导电与导热的「有效厚度」t_i = t_0·ρ_i^p（p = 3，SIMP 罚），ρ < 0.05 的格视为空（不进网格）。
- 正演：把 ρ 场写成 `ThicknessField` → `FlangeMesher.BuildFromField` 建网 → `ShellCurrent.Solve`／`ShellThermal.Solve`（APP 自己的求解器，一行不改）→ 判据。
- 灵敏度：
  - 电场是对称的有限体积拉普拉斯（面导 g = 调和平均(σt)·L/d，舌端 V=1、管孔 V=0），**伴随解 = 同一个算子换右端**，一次共轭梯度。`Pt_Topo` 自己按同一公式装配矩阵，门 = 装出来的 V 与 `ShellCurrent` 的 V 逐格差 < 1e-9。
  - 热场先不做伴随：第一阶段用 APP 的热解只做**评估**（内层把候选交给判据），电场伴随给方向、热判据做信赖域（每轮最多挖 3 % 面积，挖完热判据不过就回退一半）。第二阶段再写线性化热问题的伴随。
- 约束处理：逐格 J ≤ J+1 用 p-范数聚合（p = 8）成一条；质量是目标；热判据在第一阶段是评估门不是梯度约束。
- 可制造性：密度滤波半径 r_min = 3 mm（桥宽下限）、Heaviside 投影逼成 0/1、不许孤岛（连通性检查：每个有料块都要连到管孔或压接段）、孔径不小于 1 mm。
- 起点依赖：密度法结果依赖起点与滤波参数，与本项目「解与初值无关」那条规矩相反 ⇒ 它只当**候选形状生成器**：每个结果落成 .3dm，回 APP 用「核算整线」过全部判据，进「搜形状结果 ▾」给工程师挑，不当裁判。

## 3. 门（什么算做成）

| 门 | 钉什么 |
|---|---|
| 正演一致 | `Pt_Topo` 装配的电场与 `ShellCurrent.Solve` 逐格差 < 1e-9（同一网格、同一边界） |
| 梯度一致 | 伴随梯度 vs 有限差分（随机 20 格、步长 1e-3）相对差 < 1e-4 |
| 判据 | 优化结果写成 .3dm → APP `--cli --judge`（或核算整线）全判据过；不过就不算数 |
| 对照 | 与现有最轻解（2 段对照工况：Ø56／舌 56 不挖 2603.8 g；Y 形 2741.9 g）同工况比铂重，并给出温场／电流密度场对照图 |
| 复现 | 同一输入两次运行逐位相同（固定起点 ρ ≡ 1、固定滤波与步长） |

## 4. 分阶段与估计

| 阶段 | 做什么 | 估计 |
|---|---|---|
| 0 | 项目骨架、ρ → ThicknessField → 网格 → APP 求解器的正演管线、正演一致门 | 1 天 |
| 1 | 电场伴随 + p-范数 J 约束 + 质量目标 + 滤波／投影 + 连通性；热判据当评估门（信赖域）；对照工况跑通、出 .3dm 回 APP 判 | 3～5 天 |
| 2 | 热问题伴随（线性化的二维壳）+ 法兰增量温降／管孔净流入作梯度约束 | 1～2 周 |
| 3 | 每格厚度进变量（多级板厚），压成 2～3 级可加工的厚度 | 视阶段 1 收益决定 |

阶段 1 结束就能回答「密度法在这条线上能省多少」——R23／R29 的实测说挖孔省得不多（Ø56 约 0.5 %），阶段 1 若不超过 3 %，阶段 2、3 不做。

## 5. 收编条件

- 只有过了第 3 节四道门、且比现有最轻解省铂的候选，才考虑收进 APP；收编方式是「搜形状结果 ▾」多一个来源，界面不多一颗会跑几小时的键。
- 收编前 APP 一行不动；`Pt_Topo` 有自己的 sln，不进主 sln（提交钩子不跑它）。

## 6. 进展与偏离（2026-09-12 当天，阶段 0＋1 实做）

代码在 `D:\WinForm\Pt_Topo`（独立 git 仓库），报告 `Pt_Topo/deliverable/拓扑优化_密度法_阶段1_报告_2026-09-12.md`。与上面方案不同的地方，以及做了才知道的事：

| 方案里写的 | 实际做的 | 为什么 |
|---|---|---|
| 变量落在 1 mm 栅格，正演走 `BuildFromField` | 变量落在 **APP 解析网格的单元**上（均匀 2 mm，1788 格、设计 986 格），只改单元厚度不重建网格 | 基线（ρ≡1）就是 APP 解析路径本身，逐位对得上；一次电场解 6 ms、电+热 78 ms |
| 电场写伴随 | **有限差分**（每设计格 ρ+0.01 重解一次，一轮 50 s）；fdcheck 实测 h=0.001～0.02 差商稳定 | 求解够快，伴随不必写；热约束也一并有梯度（方案里只当评估门），比信赖域回退干净 |
| 投影梯度 + 信赖域 | **MMA**（Svanberg 1987）；密度滤波 4 mm + Heaviside β 1→32 | 五条约束标准做法；λ 要有上限（松弛变量罚系数），否则机器门抓到 x 变 NaN |
| 只挖不动别的 | **舌保温厚度一起优化** | 挖舌片让舌片变热、抽热掉到 ②′ 下面；APP 里治这条的旋钮就是舌保温；不一起优化 8 轮只省 0.25 % |
| 逐格 J ≤ J+1 | 设计区 J 峰 ≤ 基线 × 1.05（p-范数逐轮校正跟真峰） | 均匀网格上的场峰在压接段定电位边界（数值峰），拿绝对限值 11 比会把基线判成不可行 |

实测发现（收编前要报）：
1. **盘Ø56 这个基线没有可挖的盘**：管孔半径 25.8、盘半径 28，环只有 2.2 mm，就是焊环本身；拓扑只在舌片上有事做。
2. **APP 图纸路径与解析路径对同一设计判出来的不一样、不随加密收敛**（ρ≡1 共用片抽热 14.98／7.20／12.45 W 对解析 3.41 W；③ 判 121～128 K）。原因在图纸路径本身：舌保温只有一个数（`LineCase.TabInsul3dmMm`）、两条路能量平衡差约 2 %。⇒ 第 3 节「判据」那道门改成**同路同网格比 ρ≡1 与拓扑结果**；绝对通不通要把洞回到解析孔族再走加密复算。
3. 方案第 3 节「正演一致 < 1e-9」「伴随梯度一致」两门随架构改成：ρ≡1 与 APP 解析参考逐位相同（铂重 445.5、抽热 3.41、J 峰 13.85）；链式法则 vs 差分 < 1e-4；MMA 玩具题收到解析最优；逐截面 J 解析梯度 vs 差分 < 1e-4。
4. **J 约束的口径试了四种，只有「逐截面 J = I／有料格导电面积 ≤ 设计 J」是对的**（上表最后一行）。只挡场 J 峰的版本「省」14 % 是吃 APP 按 J=10 定截面留的裕量；均值型范数挖不载流的格也抬高；99 分位被压接段边界整排数值尖峰顶到 13.5。

## 7. 结果与结论（2026-09-13 早，v6 三片 80 轮 + APP 判定）

| 片 | 基线 g | 基线截面 J | 拓扑 g | 省 | 挖在哪 |
|---|---|---|---|---|---|
| 入口 | 257.8 | 9.99 | 251.8 | 2.3 % | 舌片矩形与圆盘重叠处伸出圆外的两个方角（160 mm²） |
| 共用 | 446.1 | 9.27 | 435.7 | 2.3 % | 同上 |

| 整线 | 2603.4 | — | 2570.0 | **1.3 %** | — |

- **第 4 节自己定的门槛「阶段 1 不到 3 % 就不做阶段 2、3」—— 没到，阶段 2、3 不做；算法不收编，Pt_Topo 留作研究工装。**
- 交 APP 图纸路径判（倍率 0.5，同路比 ρ≡1）：三片拓扑结果的③责任都比 ρ≡1 差 5～15 K，差的来源是舌保温被拓扑调薄（拓扑自己的模型里 ②′ 贴着下限，图纸路径里同一设计抽热却是 7～8 W，两条路的差比 ②′ 与 ③ 之间整个窗口还大）—— 拓扑给出的**几何**可信、**舌保温**不可信。
- 收编的是三条设计知识（报告第 8 节）：舌根两个圆外方角可切（锥形族新成员「舌根切角」）；电流小的片按档位取舌片厚会留 15 % 截面，允许逐片取厚更干净；图纸路径的 ③ 不可信，`TabInsul3dmMm` 要逐片、孔边界面要与解析网格对齐 —— 这是 APP 的病，拓扑把它量出来了。
