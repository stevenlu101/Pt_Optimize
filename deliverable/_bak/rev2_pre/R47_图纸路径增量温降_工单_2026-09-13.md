## 2. 修法（定了再动手；改动都在 APP，走提交钩子）

### A + E：网格轴**从管轴中心向外铺、两侧镜像**，范围取真实几何锚点
- `FlangeMesher.GradedAxis` 加一个「中心向外」的构造：从 0 出发分别向 +max 与 −|min| 铺，起步 hPrev = 0 所在带的 H（孔在细带里 ⇒ 起步就是细步），再镜像拼接。孔单元集合从此与舌长、图幅留白无关；z 轴天然对称；末格用 `min(h, max−x)` 贴合边界 ⇒ 直边 z=±zEdge 落在节点上，没有「面积折了面长没折」的部分格。
- `Build` 与 `BuildFromField` 都用它（两条路同一套轴）。BuildFromField 的范围不再取 f.X0/f.Z0，改取**真实材料包络**：`ThicknessField` 新增 `XMinMaterial/XMaxMaterial/ZMinMaterial/ZMaxMaterial`（由 `Geometry3dm.LoadThickness` 从几何包围盒填，精确到几何，不受栅格步长与留白影响）；没有时退回栅格里 t>0 的包络，并在 `ThicknessField.Warning` 里说出来。tabTipX 用 XMinMaterial。
- BuildFromField 加 `hInner/innerRadius` 参数（照 Build 的第二条 Band），LineRunner 图纸分支传 `c.MeshInnerMm/MeshInnerRadiusMm`。
- 栅格步长跟着网格走：图纸路径取 `ThicknessStepMm = min(c.ThicknessStepMm, hFine/4)`（LoadThickness 有缓存键含 step，不会重复探）；`ThicknessField.Warning` 在 h < step 时明说「已到图纸分辨率」。
- ⚠ 这一条会动**解析路径**导航网格的数（E 修掉 −z 侧粗格；140 mm 舌长 x 方向本来就对齐，z 方向会变）。实施者要量出基线设计（DesignSpec.Builtin[0] 三段、盘Ø56 记录两段）改前／改后导航网格的 ③／抽热／铂重／J 峰，**逐条列出来**，不许静默改回归数；哪些测试因此红、红的是「钉数」还是「钉逻辑」，分开报。

### B：图纸路径的保温输入逐片、从几何来
- `LineCase.TabInsul3dmMm` 改成逐片 `double[] TabInsul3dmMm`（长度 = 片数；旧标量入口保留为「同一值填所有片」的便捷属性，读旧值的地方不崩）。UI 图纸模式改用 ① 页现成的**逐片舌保温表**（解析模式在用的那张），单控件 `_tabIns3dm` 去掉或改成「一键填所有片」；上限跟解析一致（20 mm）。走查节要改（UiWiring 里碰 `_tabIns3dm`／Walk.Run3dm ④0／Map3dm 的地方），`--uishot` 抓 ① 页 3dm 模式的图。
- insulBoundaryX／tabBoundaryX 逐片：GeomForJudge 改逐片数组（分析几何变数时每片各存一份；只有一份就复制），LineRunner 图纸分支用 `GeomForJudge[j].InsulBoundaryXResolved／Tangent().X`；没有分析过就从材料包络推（切点 = 材料半宽等于盘径处的 x），推不出就拒答 ③（Undetermined，附注说明），**不许再用默认板**。
- 存档（finaldesigns/*.fd.json）：图纸路径出的档要记逐片舌保温与几何来源；旧档只有一个数 ⇒ 读回时填成所有片同值并在 Notes 里说明。

### C：.3dm 模式的加密复算与细网格重解
- `MeshVerify.Run` 加接 `Func<double h, double hInner, LineCase>` 工厂的重载（每档造 LineCase 的活从 d.BuildCase 抽出来）；.3dm 模式由 `LineDesignPage.BuildCase()` 造 LineCase 后传入，逐档同时减内带与栅格步长（D）。`RequiredMeshFor` 在图纸路径的特征尺寸从 `PlateShapeAnalyzer` 的分级取，取不到就拒答（界面写全名：「图纸没分析出特征尺寸，加密复算不能判」）。
- `FineResolveAsync` 的 .3dm 分支把 fineMm 真传给 SolveByLevel（Options 新加「终局细网格」口径，与 SearchMeshFineMm 分开）。
- `VerifyMeshAsync` 不许再用 PageToDesignSpec 造 .3dm 模式的对象；`CurrentSnap` 把几何来源、.3dm 文件名、逐片舌保温纳入。
- 门：`CliUiParityTests`／`MeshVerifyReachableTests` 补「.3dm 模式下复核用的 LineCase 走图纸路径（FlangePlates 为空、FlangeFile3dm 非空）」；「细网格重解在 .3dm 模式下网格格数随 fineMm 变」。

### F：只加自检与附注
- `ShellMesh.BuildFaces` 后自检：TagHole 面的最大半径与孔半径之差、被钉住的盘外缘长度，写进 `ShellMesh` 的诊断字段，LineRunner 把它写进判据「②′管孔净流入」的附注（「管孔定温环吃到盘外缘 x mm」），不改判定。
