## 0　结论

1. **机理**：栅格把孔圆画成台阶，台阶位置有 ±s/2 的误差。孔弧穿过的那一圈部分格里，料的面积、形心、厚度和裁剪后的面长都跟精确圆不一样。因此抽热误差是 (栅格步 s, 栅格相位) 的一个**非光滑函数**，同一个 s 换一个相位，符号和大小都会变。
   - 门只在一个相位（栅格节点落在步长整数倍上）对三个步长各取一个样本，再断言 |Δ| 单调。
   - 步 1.0 那一个样本上，F6a 把焦耳热项从 −0.768 W 翻成 +0.515 W，与散热项 +0.788 W 相抵，只剩 +0.276 W。步 0.5 的焦耳热项仍是负的（−0.181），与散热项（+0.496）同号相加，得 +0.678。于是 |Δ(1.0)| < |Δ(0.5)|，门红。
2. **离群出在孔环，不在别处**：孔环（r < rh + 3）用栅格、其余用解析，重现 +0.665 W（共 +0.678）；孔环用解析、其余用栅格，只有 +0.013 W（表 3_1「全开」）。
3. **三个候选**：
   - (a) 法向距过小：**排除**（步 0.5）。
   - (b) 台阶料与弧面并存（孔格的料形不对）：**是主因**。
   - (c) 规则 A 换批：并格数不变（24），但**并入目标换了**。它在步 1.0 上贡献 −0.165 W，在步 0.5 上只有 −0.007 W，**不是步 0.5 离群的原因**。
4. **F6 的角色**：栅格相位彩票 **F6 之前就有**，不是 F6 引入的。
   - F6a 在门的那个相位上重抽了号：步 1.0 +1.425 → +0.217（F6a 单项），步 0.5 +0.996 → +0.685。
   - 门的相位上 F6 没有放大误差：步 0.5 的 |Δ| 反而从 0.996 降到 0.678。
   - 另有一处放大，但与本红无关：在孔弧有缺口的相位上，F6（主要是 F6c）把缺口的代价放大了，步 1.0 最差 −4.030 → −6.221 W（表 7_1，全栅格 x 相位）。
5. **可辩护的修法（不挪阈值）**：图纸路径在孔圆 ±1 个栅格步的带内，按解析圆判料（r ≥ rh 有料，r < rh 无料），厚度照取栅格值。原型 B 的实测：
   - 门的两个方法 6/6 过：Builtin[0] 片0 −0.537 → −0.134 → −0.038 W，盘Ø56 片1 −0.113 → −0.022 → −0.006 W（表 9）。
   - x 相位包络变成单号、一阶收敛（表 7）。
   - 顺带消掉 §0.-20 的孔弧缺口：所有相位覆盖率都是 1。
   - 这是 §0.-20 丁 列为「根治」的那条路（在孔圆附近按解析圆判料），需业主定。

### 可辩护的修法（不挪阈值）

- **做法**：图纸（栅格）路径在孔圆 r = rh 的 ±1 个栅格步带内，按解析圆判料：r < rh 无料，r ≥ rh 有料。
  - 厚度：栅格该点有料就取该点；没料就沿射线外移一个栅格步取。
  - 带外照旧。
- **依据**：
  - 弧面本来就建在精确圆 rh 上，孔的边界已经按这个圆施加；带内的栅格台阶料与这条边界自相矛盾。
  - §0.-20 已经核对图纸孔径与 rh 的差 ≤ 一个栅格步（误差界 s/√2），带宽用同一把尺，没有新常数。带宽改成 s/√2，数值不变（表 7「原型 C」）。
- **实测**（原型 B；带内 0.005 mm 子采样积分，只是近似，不是生产写法）：
  - 门的逐条复刻 6/6 过（表 9）。

  - 单号、约一阶收敛，所有相位覆盖率都是 1。
- **没解决的**：Builtin[0] 剩下的负偏（0.1 档 −0.04 W）推测是栅格厚度对焊脚剖面的一阶误差，未验。
- **代价**：带内有料的地方孔径被强制等于 rh。小于一个栅格步的真实孔径失配会被吸收（F3 A4：+0.3 mm → G −0.9 %）。这与 §0.-20【待决定】3（尺用一个栅格步还是 s/√2）是同一个决定，**要业主定**。
- **另一条路**：只改门，不改代码（例如改判多相位包络）。这是改判法，也要业主定；而且现行代码在步 0.5 的 x 相位上最差 −2.209 W（有缺口的相位）、−0.921 W（覆盖率 = 1 的相位），生产步的 1 W 门在别的相位上会红。不建议走这条。

## 6　不覆盖、要注意的

- 相位实验只做了 x 向平移（全栅格）和孔环内的 2D 平移（孔环混合）。z 向平移会让舌直边 ±w 离开栅格节点，混进直边幻影，那是另一件事，没做。
- 平移探针第一版有错，数已作废：没平移的那一向重算了原点，浮点尾巴让 z = ±30 的节点判内判外翻面，x 平移时舌直边丢了一排料（步 0.1 上印出 −0.40 W 的假偏差）。改为照抄原栅格的原点与格数后全部重跑。作废文件放在 `deliverable/R48_图纸对拍步0p5离群_归因_证据_2026-09-23/作废_平移函数z浮点尾巴/`，本文一个数都没引用。
- 原型 B／C 的带内积分用 0.005 mm 子采样，是近似；厚度规则是原型里选的，不是推导出来的。生产实现要换精确积分（与 AnalyticMaterial 同一手法：弧与格线求交），要另过门。
- 只量了这两个算例（Builtin[0] 片0、盘Ø56 片1），没有量真 .3dm 与锥形舌。
- 机器 4 核，另有一条端到端长跑占 1 核。探针总耗时约 6 分钟。
