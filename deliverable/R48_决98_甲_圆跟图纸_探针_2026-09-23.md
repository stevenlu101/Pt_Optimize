## 0　结论（数据摘要，不含选择）

1. **量法**：五种量法在导航档（s = 0.5）上都能把 δ = 0.3 与 δ = 0 分开（尺 < 0.3、两例 × 72 个相位的区间不重叠，间隙 ≥ 0.273 mm）。最好的是新加的 **(d) 分离区间**：尺 = 0.0109（8 个 x 相位）／0.0175（再加 64 个二维相位）／0.0436（孔半径 20～28 mm 普查，10304 个样本）；而且它**逐张图纸自带误差界**（区间半宽），表 1 的 2160 个样本（三档 × (80 + 640)；两例孔周料的有无同形，a、c1、c2、d 两例逐位同值，**不同的样本只有 1080 个**）与普查的 3 × 10304 个样本里真值都落在区间里。现役 `HoleRadiusOf`（a）的实测 max|e| 在 s = 0.5 是 0.024／0.047／0.074，是 §0.-20 数学界 s/√2 = 0.354 的 7～21 %。

4. **参照本身不光滑**：生产解析 Build 的抽热对孔半径有跳变（r = 26.000 → 26.005：+0.663／+1.209 W；26.075 → 26.080：+0.693／+1.282 W；26.305 → 26.310：+0.286／+0.529 W，盘Ø56／Builtin[0]），而光滑段斜率只有约 −1.9／−5.9 W/mm。所以「对 Ref(rh + δ)」的包络里混着参照自己的跳变；用 Ref(r_量) 做参照可把它剥掉（表 2b）。

## 2　量法定义与推导

记号：栅格步 s；节点 p = (X0 + i·s, Z0 + j·s)；节点有料 ⇔ T > 1e-6（与 `FindVoids` 同一门槛）；孔空腔 = 从图幅边界填充外部空白之后剩下的最大无料连通域（照抄 `PlateShapeAnalyzer.FindVoids`，本档自检与 `HoleRadiusOf` 逐位同值）；圆心取管轴原点（网格生成器建弧面的同一个框），(c2) 另放开圆心。

| 量法 | 定义 | 用不用 rh |
|---|---|---|
| (a) 现役 `HoleRadiusOf` | r = √(N_孔·s²/π)，N_孔 = 孔空腔节点数（等面积） | 不用 |
| (b) 环带面积折算 | 环带 [R_in, R_out] = [rh − 2s, rh + 2s]；A = Σ_有料节点 面积(方格 ∩ 环带)（闭式 `RectDiskArea(R_out) − RectDiskArea(R_in)`）；r = √(R_out² − A/π) | rh 只用来放环带；值只由 R_out 与 A 定 |
| (c1) 边界中点定心均值 | 孔空腔节点与四邻有料节点连线的中点 m_k，r = mean |m_k| | 不用 |
| (c2) 边界中点 Kåsa 圆拟合 | 同一组 m_k，最小化 Σ(|m|² + D·x + E·z + F)²，r = √(D²/4 + E²/4 − F)（圆心自由） | 不用 |
| (d) 分离区间（新加） | r_lo = max_{孔空腔节点} |p|，r_hi = min_{有料节点} |p|（孔周窗口内）；r = (r_lo + r_hi)/2，自带半宽 h = (r_hi − r_lo)/2 | 不用 |

- **(b) ≡ (a) 的推导**：图纸的「料」按方格读（`ThicknessField.Integrate` 同一读法）。若 H1 碰环带的无料方格都属孔空腔、H2 圆盘 R_in 被孔空腔方格盖满、H3 孔空腔方格都在 R_out 以内，则 面积(孔空腔 ∩ 环带) = N_孔·s² − πR_in²，A = π(R_out² − R_in²) − (N_孔·s² − πR_in²) = πR_out² − N_孔·s² ⇒ r_b = √(N_孔·s²/π) = r_a。实测：假设成立的样本 max|b − a| = 3.6e-15。⇒ 在「方格读法」下，环带面积折算不含 (a) 以外的信息。
- **(d) 的推导**：栅格节点是点采样（`FlangeMesher.Rasterize` 逐节点 `g.Inside`；真 .3dm 由 `Pt_Optimize.Geom/Program.cs` `RunThickness` 在每个节点打一条射线，也是点采样）；`FlangePlate.Inside` 判料是 x² + z² ≥ R²。孔是圆心在原点、半径 R 的圆 ⇒ 每个孔空腔节点 |p| < R，每个有料节点 |q| ≥ R ⇒ **R ∈ (r_lo, r_hi]**，取中点误差 ≤ h。这是这张栅格在「圆心在原点的圆孔」假设下的最紧估计；h 逐张图纸算出，不是常数。圆心偏离或孔非圆时区间可能为空（r_lo ≥ r_hi，可作自诊断），也可能不空但偏 —— 本探针没量（见 §9）。
- 相位：x 相位用 `R48HoleBandCircleGateTests.ShiftX`（逐字照抄 G3：z 向原点与格数照抄原栅格，ox = k·s/8，k = 0…7）；二维相位用孔周窗口栅格（半宽 rh + 3，节点 (ox + i·s, oz + j·s)，(ox, oz) = (k·s/8, l·s/8)），只量量法、不解场。自检：oz = 0 时窗口与整张栅格的 a、c1、d 逐位同值（三档都查了）。

## 3　环带假设的核实（量法 b）

- **解析**（极坐标密采样：3600 角 × 径向 0.01 mm；两例 × 三档 × 五个 δ）：环带 [rh − 2s, rh + 2s] 内 `g.Inside` 与「r ≥ rh + δ」不符的点 **0**（每组 36 万～144 万点）⇒ 解析几何上环带里**料的有无**只由孔边决定，没有板缘、开槽（盘Ø56 盘半径 28、舌半宽 28；Builtin[0] 盘半径 30、舌半宽 30；两例切点 x = 0）。**厚度不止孔边**（核实补）：两例都有焊脚环 [R, R + leg]（盘Ø56 leg 1.02，Builtin[0] 0.89，都随 `HoleRadiusMm` 外移）；盘Ø56 另有舌根 x = 0 处舌板 3.03／盘 1.02 的厚度台阶，这条线穿过环带，x < 0 半圈走 `onTab` 分支、不叠焊脚（`PlateCurrent2D.ThicknessAt`）。五种量法只判 T > 1e-6，不受影响；对带内判料／JF 的影响**未量**。
- **栅格**（H1～H3 逐方格核）：
  - 盘Ø56、步 1.0：**不成立**，8 个 x 相位合计 350 个违例方格（单个相位 ox = 0、δ 0.1 为 46，核实重算），二维 64 相位合计 2590 —— 盘缘 R = 28 外的无料节点，其方格下沿到 28 − s/√2 ≈ 27.29 < R_out = 27.8。此时 b 偏 +0.04～+0.09 mm。
  - 两例、步 0.25、δ = 0.5：**不成立**（8 个 x 相位合计 3398 个违例，单个相位 ox = 0.0625 为 413（核实重算）；二维 64 相位合计 26864）—— 孔边 rh + 0.5 恰等于 R_out = rh + 2s，孔空腔方格伸出环带。此时 b 恒偏约 −0.03 mm。环带宽 2s 只在 |δ| < 2s − s/√2 ≈ 1.29 s 时装得下孔边。
  - 其余组合 0 违例，b 与 a 逐位（1e-15）相同。
- 两例孔周的料指示在所有组合上相同（同一 rh、同一栅格原点），所以 a、c1、c2、d 两例逐位同值；b 只在盘Ø56 步 1.0 不同。⇒ **表 1 两例在量法误差上不是独立样本**：不同的样本表 1 为 1080 个，导航档每个 δ 为 72 个。
