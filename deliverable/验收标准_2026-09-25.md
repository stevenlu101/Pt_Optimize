# 验收标准（2026-09-25）

适用：执行计划 2026-09-25（`deliverable/执行计划_2026-09-25_侧Y形与拓扑.md`）各交付物。判据名与限值以 HANDOVER `## 1.83`（决 103）为准；数只认证据档里的数；Linux 数是预跑，Windows 数是记录。每条写「过」的标准与「不过」的处置，不留「差不多」。

## 1 方案卡（每一张，W08／W06、每一族）

一张方案卡验收通过，须同时满足：

| # | 标准 | 怎么核 |
|---|---|---|
| 1.1 | 判决网格上求根：第二遍细网格求根做了（细区尺寸 = MeshVerify.RequiredMeshFor 给的那一对，细区半径按热点放大到「盖住」） | 证据档印「已做第二遍细网格求根」与「热点 r = …：细区盖住」 |
| 1.2 | ② 带玻璃稳态硬判据全过：法兰最热处高出管接触处温度 ≤ 10 K；管接触处流入法兰的净热流 ≤ 0 W；局部热稳定 ≥ 1（全格精算）；整片热稳定 ≥ 1；管 J ≤ 11 A/mm²；法兰截面 J ≤ 11 A/mm²；圆盘盖得住管孔＋焊脚 ≥ 0；舌片自由段 ≥ 100 mm | 三关证据档逐条「过」，裕度为正 |
| 1.3 | ③ 空管到温稳态：管 J、法兰截面 J、升温 ≤ 11；两条几何闭式过 | 同上 |
| 1.4 | ① 升温全程：8 个设定点场有效；管 J 与法兰截面 J 按设计电流与该点实际电流两条都 ≤ 11；不熔断；整片与局部热稳定 ≥ 1 | 证据档「结论：过」，逐点表齐全 |
| 1.5 | 铂重比同算例、同族的上一张方案卡（或种子设计）不重；重了就写明为什么这张仍值得交（例如换族） | 证据档铂重行 |
| 1.6 | 边界保温条件齐全：管保温三层、舌端铜排边界（定温或热导）与夹持温度、压接段长、环境温度、逐片圆盘保温、保温分界半径规则；取不到的写「未查到」 | 方案卡「边界保温条件」段 |
| 1.7 | 几何与旋钮终值可造：板厚 ≥ 0.60（焊接下界）、舌片厚与叉臂厚由 I/(J·最窄有效宽) 闭式给出、孔径 ≥ 1 mm 或无孔、桥宽 ≥ 4 mm；能出 .3dm（Windows） | 方案卡「几何」「旋钮终值」段；Rhino 出图无「实体创建失败」 |
| 1.8 | 设计可复原：按方案卡填回几何、旋钮终值、舌片厚、叉臂三件后重跑三关，铂重逐位对上、三关结论不变 | 复原探针证据档（例：`R48_方案卡_W08赢家_判决网格三关_本次开跑于2026-09-25_125324.txt`） |
| 1.9 | Windows 记录：同一设计在 Windows 上跑过三关一次，数入库并标「Windows 记录」；Linux 数只作预跑 | Windows 证据档 + HANDOVER 记录条 |

不过的处置：写明卡在哪条判据、实际值与限值、下一根可动的杠杆；不挪阈值，不改口径。

## 8 业主验收动作

1. 方案卡：对 §1 逐条打钩；不过的一条即退回。
2. 每天早上读执行计划对应阶段的证据档名单，缺一份即未完成。
3. 三个数（板料最大盘径、铜排许用温度与冷却能力、圆盘保温块最大厚度）给出后，相应「无出处」项须在下一跑改成有出处。
