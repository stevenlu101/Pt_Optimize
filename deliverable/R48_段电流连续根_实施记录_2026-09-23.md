## 0　结论

- `SegmentSolver.FindCurrent` 这一处调用改为 `Roots.MonotoneContinuous`：括号化与二分和 `Roots.Monotone` 逐字相同（求值点序列逐位相同，门 a 证），只把收尾从「末括号中点」改成「末括号内按两端函数值线性插值」。段电流由分段常数（约 2.6e−3 A 一格的二分格）改为分段连续：二分格台阶去掉了，残余台阶 1e−4～5e−4 A 量级（来自段解 Bvp1D／Picard 按容差停机，f(I) 分段光滑、带约 1e−4 K 跳跃；审查探针实测，见「审查后修改」SEG-M1）。**没有真连续**（2026-09-23 审查后改写，原写「随输入连续变化」）。

## 2　门（阈值与出处）

误差界（`Roots.MonotoneContinuous` 注释，数学推出）：f 在末括号 [lo, hi] 上二阶连续，|f′| ≥ m₁，|f″| ≤ M₂，括号宽 h，真根 r 在括号内。线性插值余项 f(x) − L(x) = ½f″(ξ)(x − lo)(x − hi)；L 的斜率等于割线斜率 s = f′(η)，|s| ≥ m₁；x̂ 是 L 的零点 ⇒

  |x̂ − r| = |L(r)|/|s| ≤ M₂·(r − lo)(hi − r)/(2m₁) ≤ **M₂·h²/(8·m₁)**；带求值噪声 |ε| ≤ ε̄ 时另加 **ε̄/m₁**（∂x̂/∂ε_lo = |f(hi)|/(|s|·|f(lo) − f(hi)|)，两端合计 ≤ 1/|s|）。

中点收尾的界是 h/2。括号不变式 f(lo)·f(hi) ≤ 0 ⇒ x̂ 永远在末括号内 ⇒ |x̂ − 中点| ≤ h/2 ≤ xTol/2。
