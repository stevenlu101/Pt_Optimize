## 1. 机理

**病。** 电流场解出电位 V 之后，逐格发热原来按重构 J 算：q_i = ρ·J_i²·t·A（`ShellCurrent` 的 TotalGenW；热场 `ShellThermal` 九处 ρ(T)·J²·t·A）。重构 J 是由各面法向通量做的最小二乘拟合，逐格 ρJ²tA 的和**不保证**等于电网络真耗散 I·U。F6 之前 W08 片0 等温闭合是 1.002～1.009，F6 之后是 0.9998～1.0004（本次门1 的「旧闭合」列：0.99975～1.00037）。差的那一份没有物理来源，是量法误差；按执行计划的换算，W08 片0 发热 386～388 W × 0.2～0.9 % ≈ 0.8～3.5 W，量级够挪逐片保温窗口（约 4 W）。

**修法（按面）。** 每条面上的发热就是 Q_f·ΔV_f（电流 × 该面两侧电位差）。每格发热取
q_i = ½ Σ_{i 的内部面} Q_f·ΔV_f；压接面（面上定电位，一侧压接格一侧自由格）与孔面（F6a 面上定电位，孔面通量 Q = g·V_A 流进管孔，ΔV = V_A − 0）那一份**整份**记给自由格。
实际单位：面的物理导度 = g ÷ ρ_ref[Ω·mm]，实际电压 = 归一化电压 × scale·ρ_ref[Ω·mm] ⇒ q_f = g·ΔV²·scale²·ρ_ref[Ω·mm]。

**为什么严格闭合（数学，不是实测）。** 内部面两侧各算一次：g(V_a − V_b)·V_a + g(V_b − V_a)·V_b = g·ΔV²；孔面 g·V_A·V_A；于是
Σ_面 g·ΔV² = Σ_电极格 1·(净流出) + Σ_孔格(老口径) 0 + Σ_自由格 V_i·(−r_i) = CurrentInA − Σ_自由格 V_i·r_i（r_i 是自由格线性残差）。
线性解精确时 Σ_i q_i = I·U；一般只差 Σ V_i r_i 与舍入。**但生产 CG（Jacobi-PCG）从零初值起步**（`ShellCurrent.Solve` 每次新建 V，只给固定格赋值 ⇒ 自由格初值 0）：x_k ∈ span{p_0..p_{k-1}}、r_k ⊥ p_j（j < k）⇒ Σ_自由格 V_i r_i = x_k·r_k 在精确算术下**对任何迭代步都为 0**。所以门1 实测 |新闭合 − 1| ≤ 1.3e-13（18 例）只反映舍入，**不反映线性残差，也证不了电位解收敛**：审查探针在 R31.00 判决网格上限定 maxIter = 5（未收敛，P_net 49.6 W，收敛值 489.7 W）时闭合仍为 −6.0e-15（`deliverable/R48_F3_审查探针_面发热分法对比与CG闭合_W08片0_4例_2026-09-23.txt`）。收敛由同一门里的 Converged 另判。印出的残差界 max|V|·Σ|r|/I_in（18 例 7.8e-8～4.4e-7）只是松界，1e-6 只比它大约 2～13 倍。GS 旧路径（LinearGaussSeidel = true，`--gslinear`，不得用于交付）不满足这一条：收敛时闭合约 8e-7（审查探针）。〔2026-09-23 审查后改写：原写「这个界很松，Σ V_i r_i 有正负相消」，机理说错了；闭合 1e-13 的来源是正交性。〕

**热场怎么吃。** 热场接口不改（ShellThermal 九处照旧 ρ(T)·J²·t·A）。电流场另交一个「发热等效 J」= √(q_i ÷ (ρ(T_解,i)·t·A))，T_解 = 本次电流解用的温度（等温解 = tRefC）。热场在 T = T_解 时逐格发热 = q_i；温度变了按 ρ(T)/ρ(T_解) 走——与原先「J 固定、ρ 随温度」同一语义。q = 0 的格取 0；t·A ≤ 0 或 ρ ≤ 0 的格也取 0，那份发热记进 `FaceGenUnplacedW`（门1 判它为 0）。

**「每面各一半」是约定。** 总量精确；局部分布是约定：
- 均匀步长、均匀 J 的条带上，面发热与 ρJ²tA **逐格相同**（两面各半 = h/2 + h/2 = 格长）；门2 实测相对差 2.2e-16。
- J 或步长沿程变化时两者不同。厚度锥形条带（t = 1 + 0.25·列号）逐格最大差 2.78 %，且逐格等于解析预测 t_i·(左 + 右)（内部面 ½·(t_a + t_b)/(2 t_a t_b)、压接面与孔面 ½/t_i），差 6.7e-16。
- 〔2026-09-23 审查后补〕**读法**：面导度 g = 调和平均(σt)·L/DistAB 恰好等于两段 DistAB/2 串联（`ShellCurrent.cs` 的面导度）。把热按「各段电阻所在的格」记，一维条带上逐格恰等于 ρJ²tA（内部面、压接面、孔面三类都如此）。所以锥形条带上 2.78 % 的逐格差是「½」相对网络自身串联分解的**误差**；门2 守的「等于 ½ 的解析预测」是**约定本身，不是物理**。原文把它写成「约定的一部分，等于解析预测」，等于把这个误差当成了目标。
- **孔边切格上发热等效 J 可达重构 J 的 4 倍**（门1 印：W08 片0 判决网格 |J等效/J重构 − 1| 最大 2.98，在 (−25.80, 0.60)，孔半径 25.800；面积 0.017 mm² 的切格分到邻格那半条面的发热）。所以发热等效 J **逐格看不是「这一格的电流密度」**，只有总量和热场里的热源分布是它的用处。这一条决定了 §2 的局部热稳定改法。
