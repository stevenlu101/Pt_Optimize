# Pt_Optimize 使用说明书

> 铂金直接加热整线设计与用量优化。
> 最后更新 2026-08-16。本说明书与代码同仓，改代码请一起改它。

---

## 0. 一页看懂

这个程序回答一件事：**在「能造能用」的前提下，这条铂金加热线最少用多少铂。**

「能造能用」不是形容词，是一组**有出处的判据**（见 §4）。程序做的是：给定几何 → 解耦合温度场与电流场 → 用 `LineRunner.Judge` 判一遍 → 报「过／不过／无法判定」和**离限值还有多远**。

已定案两档，都全判据通过：

| 档 | 铂重 | 咬住它的 |
|---|---|---|
| **管壁 0.8 · 留余量** | 3117 g | 无 —— 每条判据都有裕度 |
| **管壁 0.6 · 底档** | 2398 g | 焊接烧穿下界（余量 0）＋ 管 J 10.96/12（余量 9 %），两条同点 |

取舍属于业主：它取决于「手工 TIG 焊 0.6 mm 壁」和「0.6 mm 壁跑 11 A/mm²」这两件现场判断，不在计算里。

## 1. 三条铁律（读之前先记住）

程序里到处是这三条的痕迹，不知道它们会看不懂很多设计。

**① 判据只有一个来源。**
所有判定出自 `Core/LineRunner.Judge`。界面、命令行、报告一律只读 `AllOk` / `Failed` / `ValueOf`，**不得自己重算**。散在三处正是本项目连错四次的根源。

**② 几何只有一个来源。**
定案值出自 `Core/FinalDesign`。任何命令要「对着定案构型量」，从那里取。曾经 `--hotspot` 与 `--busbarplan` 各钉着几代之前的几何，跑得出漂亮的数 —— 但那是**另一个设计**的数。

**③ 判据不允许消失。**
只能「过 / 不过 / 无法判定」三态，**无法判定一律不算通过**。曾经有判据写成 `if (有数据) checks.Add(...)`，数据缺失时整条判据消失，`AllOk` 少判一条还报「全过」。

## 2. 界面

启动 `Pt_Optimize.exe`，四个页签。

### 2.1 整线设计（主力页）

工具条：

| 按钮 | 做什么 |
|---|---|
| **核算整线** | 按页面上的参数解一次，出判据表 |
| **自动定厚** | 让优化器调四片法兰厚度 |
| **定案档 ▾ + 载入定案** | 把 `FinalDesign` 的某一档灌进各控件 |
| **导出定案 3DM** | 出整机几何（见 §5） |
| 导出 .3dm | 只导法兰板（旧功能） |

> ⚠ **「载入定案」有两项控件表达不了**，界面上看不到但内核里生效：
> **管孔两级渐变环**（相对板厚的倍率）与**逐片舌保温**（四片差 12 倍）。
> 载入后输出框会把这两项列出来。想复现定案数，用**导出定案 3DM** 或命令行
> `--busbarplan --wall 0.6`；本页的「核算整线」走的是页面上这些参数。

### 2.2 判据表怎么读

```
  ★ ②″圆盘区最高温     0.960 /  5.000     81%  ✓  入口
  │  │                  │        │          │   │  └ 位置
  │  │                  │        │          │   └ 过／不过／? 无法判定
  │  │                  │        │          └ 裕度 = 离限值还有多远
  │  │                  │        └ 限值（出处见 §4）
  │  │                  └ 实际值
  │  └ 判据名
  └ ★ 硬安全线／○ 设计目标／· 参考量（只报数不判）
```

**裕度这一列比「✓」有用。** 本项目最常见的错就是**贴着限值判过与不过**——
曾经用 0.02–0.08 K 的差别决定了 700 g 铂金，而那点温差只对应 **14 mW**、
占段功率 5 ppm，现场任何仪器都测不出来。

⇒ 看到 ✓ 先问两句：**这个裕度比数值噪声大吗？比现场能分辨的尺度大吗？**

### 2.3 收敛信息（判据上方的 ⓘ 行）

```
  ⓘ 外层耦合 10 轮收敛（剩余误差估计 0.65 K = 步长 0.25 × 放大 2.5，ω=0.35）
```

- **剩余误差** = 距不动点的估计 `δ·r/(1−r)`，**不是**「相邻两轮变化 δ」
- 曾经用 δ 当收敛判据：δ=1.36 时报「5 轮收敛」，而真实剩余误差约 34 K
- **未收敛时会打「⚠ 下面每个数都不可引用」** —— 那不是提醒，是字面意思

## 3. 命令行

界面之外还有 CLI（`Pt_Optimize.exe --cli <命令>`）。常用的几条：

| 命令 | 用途 |
|---|---|
| `--final2` | **可行性阶梯**：管壁从宽到窄逐档定尺寸，报最薄的全过档 |
| `--busbarplan [--wall 0.6]` | 定案构型的铜排尺寸与位置（**自检整线是否全过**） |
| `--make3dm [--out 目录]` | 两档定案 3DM + round-trip 校验 |
| `--hotspot [--wall 0.6]` | 峰值位置实测（坐标、局部 J、局部厚度） |
| `--knob2` / `--ring` / `--tins` | 三个旋钮的斜率实测（只测不调） |

`--wall` 给了不认识的值会**抛异常**，不会静默回退到默认档。

## 4. 判据与限值出处

**每条限值都必须有来源。** 这是审计过的常驻表：

| 判据 | 限值 | 出处 |
|---|---|---|
| ① 升温 空管到目标 | 72 h | 业主「≤ 3 天」 |
| ②′ 管孔净流入 | **> 0** | 总纲 C2 下半条「为负即法兰比管热」——方向性判据 |
| ②″ 圆盘区最高温 − 管温 | **5 K** | 现场控温精度 ±5 K |
| ③ 法兰增量温降 | **10 K** | 总纲 C2；**业主明确：这个 10 是贴着热偶误差定的** |
| 管 J | **12 A/mm²** | 现场：一般上限 15，管壁 0.6 时 12 是极限 |
| 管壁下界 | **0.6 mm** | 手工 TIG 烧穿下界（自动 TIG 0.3、激光 0.1） |
| · 法兰 J_max | 10 | **无依据，待定** ⇒ 降为参考量 |
| · ④ 管强度利用率 | 1.0 | 蠕变已被业主划掉 ⇒ 参考量 |
| · 玻璃温降 | 20 K | **现场实测**，全模型唯一校准点 |

### 关于 ③ 的 10 K，必须说清楚

| | |
|---|---|
| 出处 | 现场铂热偶 >1000 °C 的误差 ±10 K |
| 物理依据 | **未知 —— 没有数据** |

**不得据此声称「超过 10 K 也安全」，也不得声称「真实限值是 X」。**
10 K 就是要遵守的要求。但知道刻度来源后有两条推论：

1. **不该把设计点摆在 10 上** —— 摆在测量地板上的判定分不出真假
2. **不该拿它当控制靶** —— `∂③/∂板厚 = +149 K/mm` 是**正号**，
   靶设在 ③=8 会让优化器**加厚板**把 ③ 推向限值，花铂金把判据推坏

## 5. 定案 3DM

`--make3dm` 或界面「导出定案 3DM」。内容：

```
铂管            3 段 Ø50 × 壁厚，沿 Y 轴，各 300 mm
入口-板身       圆盘 Ø60 + 舌片 90×30 + 舌根圆角 R3
入口-环外级     r ∈ [孔+3, 孔+6]，厚 = 板厚 × (1+0.4(μ−1))
入口-环内级     r ∈ [孔, 孔+3]，厚 = 板厚 × μ
入口-压接段     自舌端往回 40 mm（参考几何，非铂件）
共用1- / 共用2- / 出口-  同上
```

**图层按片分**，不按类型分。两个理由：交付件要能单独调出某一片；更硬的是**厚度探针沿 Y 打射线，而四片正是沿 Y 排成一列** —— 同层会被一次穿透、厚度加起来（实测量得 10.450 = 2.11+3.40+3.18+1.76）。

### round-trip 是硬性验收项

写完立刻**从磁盘读回**，量每个实体的包围盒，判据是 **沿 Y 的跨度 = 板厚**。

为什么非做不可：2026-08-12 出过一次事故 —— 板画在 XY 面、沿 Z 拉伸，与读取端的「XZ 面、厚度沿 Y」差 90°，**自己写出的 .3dm 再读回来量到 0 材料**。文件能打开、图看着对，数是错的。若哪天方位又错了，Y 跨度会变成盘直径而不是板厚，一眼露馅。

## 6. 已知坑（不看这节会重犯）

| 坑 | 形状 | 怎么发现 |
|---|---|---|
| **代理量当原量** | 拿邻近的量顶替判据／靶／收敛度量 | 一天犯三次：拿段内最大偏差当管根、拿 B 当 ③ 的靶、拿会切换分支的标量当收敛度量 |
| **默认值当需求** | 冻结的占位值被当成给定条件 | 已十次。**每个冻结值都要扫一遍**，哪怕最后证明它是对的 |
| **参数写绝对值** | 依赖项一动，对策静默失效或被悄悄重画 | 渐变环写绝对半径 ⇒ 板一变厚环就消失，整条阶梯从来没有环 |
| **修一个漏一个** | 新旋钮写在旧旋钮的 `continue` 之后 | 优化器报「都到位」停机，实际差 0.01 K |
| **收敛容差粗于判据分辨率** | 判据在读求解器的残差 | 容差 1.0 K 而 ②″ 在 0.01 K 上判过不过 |

**共同点：不报错、输出格式正常、数值看着合理 —— 但结论是错的。**
唯一可靠的抓法是**交叉核对**：任何「通过」的结论，用另一个独立的数验一遍。

## 7. 现场还需要确认的数

| 量 | 现状 | 影响 |
|---|---|---|
| 法兰 J 的许用值 | **无依据**（现取 10，已降为参考量） | 法兰 J 实测 34，这条一旦成为硬判据会大幅改变结论 |
| ③ 的物理依据 | 只知刻度来自热偶误差 | 决定能否把设计点从 10 K 往外放 |
| 铜排表面状态 | 按氧化铜 ε = 0.7 算 | 抛光铜只有 0.05，**差 14 倍**，散热段长度直接翻几倍 |
| 焊接方法 | 按手工 TIG（下界 0.6） | 改自动 TIG 可到 0.3、激光 0.1，**差一个量级** |
