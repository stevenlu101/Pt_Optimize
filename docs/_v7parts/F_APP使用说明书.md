图形界面：

```bash
dotnet Pt_Optimize/bin/Release/net8.0-windows/Pt_Optimize.dll
```
<!-- 出处: Pt_Optimize/Pt_Optimize.csproj:5 TargetFramework net8.0-windows -->

命令行（同一个可执行文件，加 `--cli`）：

```bash
dotnet Pt_Optimize/bin/Release/net8.0-windows/Pt_Optimize.dll --cli --help
```

`--help` 列出全部命令，并按 `DesignSpec.All` 实时列出设计记录。那份清单不在本文件里维护，改了代码它自己就变了。<!-- 出处: Pt_Optimize/Program.cs:6148-6158 -->

## 2. 构建

```bash
dotnet build Pt_Optimize.sln -c Release
```

解决方案里有三个项目。前两个的目标框架故意不同，不要「统一」它们：<!-- 出处: Pt_Optimize.sln:6-10 -->

| 项目 | 框架 | 为什么 |
|---|---|---|
| `Pt_Optimize` | net8.0-windows | 主程序 |
| `Pt_Optimize.Geom` | net7.0-windows，x64 | Rhino 8 引擎是 .NET 7，进程内宿主必须同代；RhinoCommon 8 只有 64 位；必须独立进程 |
| `Pt_Optimize.Tests` | net8.0-windows | 测试 |
<!-- 出处: Pt_Optimize/Pt_Optimize.csproj:5；Pt_Optimize.Geom/Pt_Optimize.Geom.csproj:16-17,23-24；Pt_Optimize.Tests/Pt_Optimize.Tests.csproj:4 -->

几何子进程需要本机装 Rhino 8。没装时主程序照常运行，只有 3DM 相关功能报错。<!-- 出处: Pt_Optimize.Geom/Pt_Optimize.Geom.csproj:16；docs/APP使用说明书.md:55（v6.1） -->

Linux 上只能编译和测试 Core 与不碰界面的测试，走 `tools/linux_mirror`。界面、`Program.cs`、几何子进程、界面走查、抓图只能在 Windows 上跑。<!-- 出处: HANDOVER.md:50；HANDOVER.md:69 -->

### 两个会浪费半天的坑

- WebView2 版本钉死在 1.0.4078.44（本机缓存里有）。改成别的版本会触发一次完整 restore，实测 48 分钟。<!-- 出处: Pt_Optimize/Pt_Optimize.csproj:28；docs/APP使用说明书.md:59-60（v6.1） -->
- `dotnet run` 的参数会被吃掉：`dotnet run --project X -c Release -- args` 里 `--nologo` 之类的会混进 args。要传参数就直接跑 `bin/.../*.exe`。

## 6. 操作说明（纯文字版）

### 6.1 这个软件做三件事

它算的是铂金直接加热的一整条线：几段铂管串起来通电，管与管之间用铂法兰当电极。
给出管子、法兰形状和工况，它回答三个问题：能不能造，能不能用，要多少铂。
省铂只在前两条都过了之后才谈。<!-- 出处: Pt_Optimize/UI/ManualPage.cs:976-979 -->

| 想做什么 | 怎么做 | 看哪里 |
|---|---|---|
| 算一个设计要多少铂、过不过 | 「① 输入」页填参数，或选一张 .3dm 图纸；到「② 法兰优化」页点「核算整线」 | ③ 页判据表，先看裕度那一列 |
| 出图纸交给加工 | 到「③ 结果与出图」页点「导出本页 3DM」 | ② 页输出框里的读回校验与重量对账 |
| 改个参数看看会怎样 | 改左侧参数表或 ① 页上的框；停手后它自动解一次 | 判据表与三张场图 |
| 给一个形状，让它自己定厚度并说出好坏 | ① 页填盘径、舌宽；② 页点「核算整线」，或展开「手动分步 ▾」点「自动定厚（手动分步）」 | 形状体检报告（见 6.7 节末） |
| 看每片配多粗的铜排、包多厚保温、焊多大焊脚 | 算完后看 ③ 页「配套清单」「保温方案」页签；要整线说明，看「安装报告」页签并点「导出安装报告」 | 配套清单逐片一行；保温方案每区一行 |
| 连盘径、舌宽、锥形、挖不挖孔都让它去搜 | ② 页「手动分步 ▾」里点「◇ 搜形状（手动分步）」 | 每算完一个形状出一行；全部候选在「搜形状结果 ▾」里 |
<!-- 出处: Pt_Optimize/UI/ManualPage.cs:980-998；Pt_Optimize/UI/Flow.cs:266-352；Pt_Optimize/UI/LineDesignPage.cs:1177-1178,1192-1196,5593 -->

「核算整线」读的是页面上的数。页面上的几何和设计记录用同一套画法，所以「载入设计记录」之后点「核算整线」，算的就是记录里那个设计。<!-- 出处: Pt_Optimize/UI/ManualPage.cs:999-1000；Pt_Optimize/UI/Flow.cs:269 -->

页面上没有框的是角焊缝，焊脚 = max(板厚, 壁厚)。每次算完，输出框把压接段、逐片舌保温、渐变环、舌根圆角、角焊缝、圆盘保温的实际用值逐条列出来。看不见却在起作用的量最容易出事，所以一定印出来。<!-- 出处: Pt_Optimize/UI/LineDesignPage.cs:1076-1110,4855-4867,2738-2749 -->

### 6.2 窗口分三块，页签五个，主线三页

窗口分三块：<!-- 出处: Pt_Optimize/UI/ManualPage.cs:1007-1021 -->

| 右上 | 状态面板 | 现在算的是哪条链、结果还新不新鲜、上次判定、下一步点哪个。上面有一行「下一步 → 点『…』」 |
| 右下 | 五个页签 | 「① 输入」「② 法兰优化」「③ 结果与出图」「参考工具」「使用说明」。按做事的顺序从左到右排 |

③ 页有一道门：要有一个当前参数的、解得出来的解。过没过、准不准不拦；出图和另存时，程序把超标的项列出来，由工程师决定存不存、出不出。没解出来、或者解完之后参数又动过，门就关着。<!-- 出处: Pt_Optimize/UI/Flow.cs:401-418 -->

门关着时，状态面板上有「我知道风险，越关进入 →」。越关进来的页面会挂一条提示：本页所有结果不可引用。越关只在这一次运行里有效，参数一动就作废。<!-- 出处: Pt_Optimize/UI/StagePanel.cs:141,285；Pt_Optimize/UI/Flow.cs:900-903,963-967 -->

### 6.3 逐个按钮

| 在哪一页 | 按钮 | 做什么 | 耗时 |
|---|---|---|---|
| ① 输入 | 分析几何变数 | 只在 Rhino .3dm 文件模式下可用。读入口片 .3dm，反推出管孔、盘径、舌片尺寸与各级台阶厚度 | 分钟级 |
| ① 输入 | ◈ 图纸几何 → 参数 | 要先做过「分析几何变数」。把 .3dm 反推出来的几何（盘径、舌长、舌半宽、管壁、板厚）交给解析路，并切到解析模式。之后「◇ 搜形状（手动分步）」才可用。图纸本身不改，切回去即可 | 瞬时 |
| ② 法兰优化 | 核算整线 | 一路算到能出图为止：解一次，判据没过就自己调厚度，必要时连形状一起搜，再加密复算到数不再变 | 十几分钟到两小时，全程有进度，随时可取消 |
| ② 法兰优化 | 自动定厚（手动分步） | 要先有当前参数的收敛解（点过「核算整线」并收敛），否则灰着。「核算整线」已经包含这一步。单独点是只调厚度、先看一眼。解析几何走定尺寸求根，.3dm 几何走逐级定厚。结束后附一份形状体检 | 数分钟到半小时，可取消 |
| ② 法兰优化 | ◇ 搜形状（手动分步） | 要先有当前参数的收敛解，否则灰着。「核算整线」已经包含这一步。自动改盘径与舌宽（舌长按装配算），逐个定尺寸，挑最轻的全过解。只在解析几何模式可用 | 几十分钟 |
| ② 法兰优化 | ◆ 加密复算（算到数不再变） | 要先有当前参数的解（图纸模式还要先分析过）。把网格一档档加密，直到判据不再变。判据可不可信由它说了算。复算收敛之后接着跑终验三关与舌保温可行窗口（见 6.10、6.11 节） | 10 到 40 分钟，可取消；终验另计 |
| ② 法兰优化 | ◆ 细网格重解（加密不过后） | 加密复算发现判据在细网格上不过、导航网格上是过的：直接在这张细网格上重新求根，每一遍之内旋钮只增不减，两遍之间有回收。解完仍要回「◆ 加密复算」再验一次 | 十几分钟到数小时，可取消 |
| ② 法兰优化 | 导出可回读 3DM | 把本页解析几何写成单图层多级台阶的 .3dm，APP 自己读得回来。写完立刻回读校验 | 十几秒 |

### 6.7 判据表怎么读

判据表在 ③ 页上半部。一行是一条判据。列：类别、判据、实际、限值、裕度、判定、位置。<!-- 出处: Pt_Optimize/UI/LineDesignPage.cs:4218-4224 -->

- 类别：「硬」= 卡交付；「目标」= 卡交付（目标）；「参考」= 只印值，不卡交付。<!-- 出处: Pt_Optimize/UI/LineDesignPage.cs:5175-5176；Pt_Optimize/Core/Criteria.cs:250 -->
- 判据：界面名，后面括号里是单位。界面上不出现判据代号。<!-- 出处: Pt_Optimize/UI/LineDesignPage.cs:5198-5204 -->
- 裕度：离限值还有多远，印成百分数；越限印「超 x %」。越大越稳。贴着限值的过不算真过。参考量的裕度一栏印一条短横。<!-- 出处: Pt_Optimize/UI/LineDesignPage.cs:5180-5188 -->
- 判定：✓ 过，✗ 不过，? 无法判定，参考量印一条短横。<!-- 出处: Pt_Optimize/UI/LineDesignPage.cs:5189 -->
- 行的底色：不过是淡红加粗，无法判定是淡黄，参考量是灰字。颜色只重复判定，不产生判定。<!-- 出处: Pt_Optimize/UI/LineDesignPage.cs:5207-5216 -->

### 6.9 收敛信息、认证误差与「判不了」

每次整线解完，输出框里有一行外层耦合的收敛信息：几轮收敛、剩余误差估计、放大、认证误差、容差。<!-- 出处: Pt_Optimize/Core/LineRunner.cs:1878-1891 -->

- 容差：外层耦合的停机容差是一个绝对目标，0.025 K，不随判据裕度走。<!-- 出处: Pt_Optimize/Core/LineRunner.cs:463 CoupleTolK = 0.025、:1886-1887 -->
- 认证误差：停机时「这个数还会晃多少」。认证误差 = 放大 × 停机残差。放大取「闭式估计 × 1.1」与「实测雅可比」两者之大。<!-- 出处: Pt_Optimize/Core/LineRunner.cs:1013-1019,1881-1883；HANDOVER.md:331-334 -->
- 判不了那么细：硬判据里单位为 K 的，若裕度的绝对值小于认证误差，就判「判不了那么细」，既不当过也不当不过。判据表里这一行是「?」。要判得了，得把这一点解得更细（细网格，或更细的容差重算）。单位为瓦的「管孔净流入」不进这个名单。<!-- 出处: Pt_Optimize/Core/LineRunner.cs:1916-1919,2582-2604 -->
- 写「未收敛」时，下面每个数都不能用。这是字面意思。<!-- 出处: Pt_Optimize/UI/ManualPage.cs:1326；Pt_Optimize/UI/StagePanel.cs:244 -->

### 6.15 三条规矩

1. 判据只有一个来源：整线计算判出来的表。界面、报告只读它，不自己再算一份。
2. 几何只有一个来源：设计记录。出的图、算的场、画的示意图都从它来。
3. 判据不会消失：卡交付的判据只有过、不过、无法判定三种，无法判定不算通过。参考量只印值与裕度，不印过或不过。

### 6.16 常见问题

| 现象 | 其实是 |
|---|---|
| 「◇ 搜形状（手动分步）」是灰的，点不动 | 现在是 .3dm 图纸模式，形状由图纸给定，要搜先点「◈ 图纸几何 → 参数」；或者当前参数还没点过「核算整线」并收敛 |
| 选了「（已作废）…」那两档，导出 3DM 没反应 | 故意拦住的。已作废的档不许出图，输出框说明为什么作废 |
| 判据全过，但数看着不对 | 先看输出框的收敛信息。写「未收敛」时，下面每个数都不能用 |
| 判据表某一行是「?」 | 无法判定：没收敛，或裕度小于认证误差（判不了那么细）。无法判定不算过。把这一点解得更细，不要去改形状 |
| 两个按钮给的数不一样 | 一个算的是存好的设计记录，一个算的是改过的页面 |
| 核算整线停在「法兰侧旋钮到顶」 | 核算整线会自己接着搜形状。停在这里，说明形状也搜过了（或走满 8 步、两步的结果逐字未变、或是图纸模式），要改输入：控温点、管径与管壁、铂牌号，或放宽这一段的工况 |
| 核算整线停在「判不了」 | 某一点没解到收敛。加轮数上限，或点「◆ 加密复算（算到数不再变）」在细网格上重算。这不是形状的事 |
| 搜形状结果比设计记录重 | 它保证过，不保证比记录省。从更好的起点重搜，或在「搜形状结果 ▾」里挑 |
| 搜形状标题写「精算没有全过」，页面没变 | 这一族没有全过的形状，所以不写回页面。粗筛那一行仍在「搜形状结果 ▾」里，要看就选它 |
| 加密复算后从过变不过 | 粗网格把孔边和焊脚那一圈的梯度抹平了，细网格才是真的。点「◆ 细网格重解（加密不过后）」在细网格上重解 |
| 三关结论写「没跑」 | 参数表里那个开关关掉了，或者是图纸模式。没跑不等于过 |
| 「舌保温可行窗口」写「本次没量」 | 参数表里「终验时量每片舌保温的可行窗口」关掉了，或者还没做加密复算，或者是图纸模式。没量不等于缠得出来 |

### 6.17 现场还需确认的数
