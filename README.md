# Pt_Optimize

铂金直接加热系统（供料管 + 法兰）的用量优化。WinForms / net8.0-windows。

**目标函数：在满足全部约束的前提下，使铂金总质量最小。**

```bash
dotnet run --project Pt_Optimize
```

| CLI | 作用 |
|---|---|
| `--cli [case.json]` | 一维管段求解摘要 |
| `--cli --couple` | 一维管段 ↔ 二维法兰 耦合（Pt_Heater.3dm 真实几何） |
| `--cli --save` | **省铂曲线**：热工况 → 功率 → 电流 → 可减薄量 → 铂重 |
| `--cli --curve <dir>` | 省铂曲线细扫描 + 出图 `saving_curve.png` |
| `--cli --insul` | 法兰保温分界位置扫描 |
| `--cli --thick` | 孔周局部加厚扫描（治 J 越界） |
| `--cli --plate` | 二维法兰电流场 + 温度场（独立） |
| `--cli --plots <dir>` | 导出连接区场图 PNG |
| `--cli --geom` | 读 `Pt_Heater.3dm` 校核代码里的几何常数（起 `Pt_Optimize.Geom` 子进程，需装 Rhino 8） |

验证：`dotnet test`（15 项）

## 结论：省 34 %，约 1006 g 铂

| | 现状 | 推荐 |
|---|---|---|
| 法兰冷却 | 压缩空气吹风 | **停吹风**，全包高纯氧化铝纤维 |
| 保温分界 | X = −80（覆盖 53 %） | **X = −200（全包）** |
| 铜排夹 | 自由辐射 | **水冷 80 °C** |
| 孔周 | 均厚 2.0 mm | **r ≤ 40 mm 加厚至 3.0 mm** |
| 管壁 | 1.000 mm | **0.561 mm** |
| 法兰厚 | 2.00 mm | **1.37 mm** |
| **总铂** | **2966 g** | **1960 g（−33.9 %）** |
| 析晶裕度 | −122 K ✗ | **+57 K ✓**（要求 ≥ +40） |
| J 管 / 法兰 | 7.63 / — | 10.00 / 10.00（卡在许用值） |

### 链条

```
停吹风 + 全包保温 ──→ 法兰抽热 267 → 145 W/片 ──→ 析晶裕度 −122 → +49 K
        + 水冷夹 ──→ 抽热 145 → 59 W/片        ──→ 裕度 +49 → +168 K
                                                    ↓ 富余兑换成减薄
        管壁 1.00 → 0.561 mm ──→ 电流 1199 → 892 A ──→ 法兰 J 下降
                                                    ──→ 法兰 1.82 → 1.37 mm
                                                    ──→ 总铂 −34 %
```

管子和法兰**一起瘦是复利**：管壁减薄抬高段电阻，同功率下电流下降，法兰的 J 随之下降，法兰也能减薄。

停在 0.561 mm 的原因**不是析晶**（还剩 +57 K），而是**管子的 J 打到 10.00 A/mm² 许用上限**——约束换人了。

### 吹风为什么贵

由质量方程 $m = d_{Pt}P/(\rho_e J^2)$，**吹掉的每一瓦都要由铂金发出来，直接折算成克数**。现状法兰抽热 267 W/片，水冷方案只有 103 W/片且是有用功。吹风是在用铂金买安全。

### 落地前需确认

1. **0.561 mm 管壁能否加工装配**（Ø50×300，属行业薄壁端 0.5–1.0）。若实际下限 0.8 mm，则省 16.7 %（496 g）。
2. **水冷夹结构与铂-铜接触热阻**——模型把舌片末端整条边设为 80 °C 定温。
3. **停吹风的过渡监测**。

## 几何来源

`Pt_Heater.3dm`（rhino3dm 提取，图层 `铂金管` / `法兰`）：

```
铂金管  Ø52/Ø50 → 壁厚 1.0 mm，长 300 mm，导电截面 160.2 mm²，1031 g
法兰    厚 2.0 mm，圆盘 Ø120，管孔 Ø52，舌片伸出 200 mm、末端宽 80 mm
        切点 x = −6.06 / 半宽 59.69（与 .3dm PathStart 独立吻合）
        平面净面积 23 591.6 mm²，单片 1012 g
保温    管：全段（氧化铝纤维 10 mm + 致密氧化铝套管 5 mm，先裹布后套管）
        法兰：X ≥ 分界 包覆纤维；其余裸露
电源    单相交流，可控矽相控；舌片末端整条边压接铜排
```

舌片末端截面 **160.0 mm²** ≈ 管截面 **160.2 mm²** —— 刻意配的。

上述数字不再是手抄：`--cli --geom` 起 `Pt_Optimize.Geom` 子进程（net7.0-windows / x64 /
Rhino.Inside，自带 headless Rhino 8 引擎）量测 `.3dm`，主程序拿回 JSON 与自己的常数逐项对照，
2026-08-09 实测 11 项全部 0.00 % 吻合（含平面净面积 23 591.608 mm²）。
主程序本身不引用 RhinoCommon，没装 Rhino 的机器照常构建与核算。

## 物理模型

见 `docs/Pt_理论模型.md`，生成 Word：

```bash
pandoc docs/Pt_理论模型.md -o docs/Pt_理论模型_v2.0.docx --toc --toc-depth=3
```

```
q_v = ρe(T)·J²                    体积生热（由 J = σE 推出）
m   = d_Pt·P / (ρe·J²)            质量方程 —— J 钳死时铂量 ∝ 功率
J   ∝ t^(−1/2)                    壁厚与电流密度
ℓ   = √(k·A/β)                    热衰减长度
|ΔT_dip| = D / √(k·A·β)           法兰抽热造成的管根冷点 —— A ∝ t，
                                   减薄省铂却加深冷点（本问题的核心冲突）
S   = β·A / (I²·dρe/dT) > 1       恒流热稳定判据（β 用切线斜率）
```

## 求解器

| 模块 | 方程 | 验证 |
|---|---|---|
| `Bvp1D` | `d/ds(K dT/ds) + S(s,T) = 0` 通用一维内核，管段（s=x）与法兰径向（s=r）共用 | MMS 观测阶 1.99–2.00；解析肋片解 <1e-3；能量闭合 <1e-9 |
| `SegmentSolver` | 管段金属 + 玻璃耦合，外层解电流与壁厚 | 中点打靶 <0.5 K；J ≤ J_allow；质量方程自洽 1e-16 |
| `PlateCurrent2D` | `∇·(σ(T)·t·∇V)=0`，掩膜网格五点格式，变厚度 + σ(T) | 电流守恒 1.3e-3；网格收敛 0.8 % |
| `PlateThermal2D` | `∇·(k t ∇T) + q_v t − 2q″(T) = 0`，分段 q″，可选水冷端 | 逐格残差 Σ\|R\| ≈ 0；能量闭合 1.9e-7 |
| `CoupledSolver` | 外层不动点：管段 ↔ 二维法兰 ↔ σ(T) 电流场 ↔ 法兰厚度定尺 | \|ΔD\| < 2 W，2–3 次收敛 |

依赖：MathNet.Numerics（三次样条解析导数、Brent）、ScottPlot 5、xUnit。

**ScottPlot 离线安装**：SkiaSharp 原生包较大，网络差时用 `dotnet restore --disable-parallel` 串行还原。
不要用 `dotnet add package`——它失败时会回滚 PackageReference，看起来什么都没发生。

**求根策略**：管段电流用**二分**而非 Brent——残差每次要解一遍非线性 BVP，带迭代噪声，
Brent 的逆二次插值会放大噪声跳到错误分支。搜索上界钉在热稳定极限
`I_stab = √(β·A/(dρe/dT))` 之内，越界则抛错而非返回夹断值。

## ⚠ 已作废

**一维环形法兰模型**（`FlangeRadial`、`FlangeOptimizer`、`--opt`）按环形圆盘建模，
与实际的「圆盘 + 平面梯形舌片」几何不符。以下结论无效：

- Φ = 0.037（真值 0.72–0.82）
- 「法兰 849 g → 12 g」优化建议
- `r_o,max = √(C/t_min)` 可制造性判据与联合扫描表
- 理论模型 §8.9「管壁减薄补偿」（管壁不可能渐变）

**`--flare`（舌片延长/加宽）** 也已作废：加宽虽能把铜排接点从 1235 降到 338 °C，
但析晶裕度掉到 −26 K 且铂重涨到 4341 g。水冷夹方案比它省 2.4 kg。

`--cli` 主输出的「法兰 Φ」「析晶裕度」两行走旧模型，**以 `--couple` / `--save` 为准**。
