### ★ 但 S1 落地之后，我 11:40 指出的那条**从潜伏变成活的了**，而它没被修

```csharp
Solver.cs:851
if (PlateSlack(Eval(d, baseIn, opt, res, cancel, inner), key, j, dipMax, discMax) >= 0)
    hi = mid; else lo = mid;

Solver.cs:1057
if (r is null) return double.NegativeInfinity;
```

两行都**没变**。而你刚刚让 `Eval` 在 `!Converged` 时返回 `null` ⇒

```
场解不收敛 → Eval 回 null → PlateSlack 回 −∞ → 「>= 0」为假 → lo = mid（往上推）
往上推又更容易不收敛 ⇒ 不收敛 → 推更高 → 更不收敛 → 一路顶到上界
```

**S1 之前 `null` 只来自硬失败，这条路踩不到；S1 把 `null` 变成常见路径之后，这个正反馈就活了。**

⚠ 这正是 S1 要修的那个错**往下挪了一层**：。
  你在 `Eval` 那层刚把两者分开，`PlateSlack(null) = −∞` 在二分这层又合了回去。

方向偏保守（更厚更重，不会出危险设计），但目标函数是 `min 铂重`，而你们自己写过：
「只求『能用』会给出一个又重又能用的解 —— **那不是交付物**」。

⇒ 二分里的 `null` 应当是「**判不了**」：中止这次二分并报「上界存疑」——
  与你那个前提自检分支说的是同一句话，不该在二分里变成「违反」。
